SALINAN SOURCE GAME 5R

Sumber: https://wafaabdaniazamzami-blip.github.io/5r/
Tanggal pengambilan: 15 Oktober 2026

ISI
- original.html: source halaman asli tanpa perubahan.
- index.html: salinan dengan referensi library QR lokal jika berhasil diunduh.
- styles.css dan app.js: ekstraksi CSS dan JavaScript untuk dibaca/diedit. index.html tetap menggunakan kode inline asli.
- vendor/: library eksternal yang berhasil disertakan.

CARA PAKAI
Ekstrak ZIP, kemudian buka index.html di browser.

BATASAN
Library QR sudah disertakan secara lokal.
Halaman merujuk Google Apps Script dan layanan QR eksternal. Kode server Google Apps Script tidak tersedia dari source halaman ini, sehingga tidak disertakan. Fitur yang menghubungi server tetap membutuhkan internet, layanan asal yang aktif, serta izin browser/server yang sesuai.
Source telah disalin dan diperiksa sintaksnya, tetapi seluruh fitur belum diuji di browser. Tidak ada data yang dikirim ke layanan tersebut saat penyalinan.

Hak dan pemberitahuan dalam source asli dipertahankan.
